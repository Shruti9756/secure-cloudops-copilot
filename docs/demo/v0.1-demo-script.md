# SecureCloudOps Copilot — V0.1 Demo Script

> Status: Optional interviewer walkthrough. It is not required to complete V0.1.
> Target duration: 2–3 minutes
> Audience: SDE-2 interviewer, engineering hiring manager, or technical reviewer

## Purpose

Use this script when explaining the project live. The committed screenshot evidence in `docs/release/screenshots/` is the required V0.1 visual proof.

## Suggested walkthrough

### 1. Introduce the project

Say:

> SecureCloudOps Copilot is a secure local incident-investigation assistant. It answers questions only from tenant-scoped operational evidence, such as approved runbooks and deployment records. It cites evidence, refuses unsupported answers, redacts secrets before storage, and does not perform infrastructure actions.

Mention the stack:

- Next.js frontend and FastAPI API
- PostgreSQL with pgvector for semantic retrieval
- Redis for response caching and request rate limiting
- Ollama for local embedding and answer generation
- Docker worker for document processing
- Read-only MCP server for bounded tool access
- Amazon S3 and Terraform for redacted document storage
- Prometheus, Grafana, and GitHub Actions for observability and quality checks
