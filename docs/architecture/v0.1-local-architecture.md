# V0.1 Local Architecture

## Purpose

This diagram describes the first locally runnable version of SecureCloudOps Copilot.

V0.1 supports document upload, RAG retrieval with citations, Redis caching/rate limiting, and Amazon Bedrock model calls. MCP tools, multi-tenancy, and full AWS deployment are planned for later versions.
